A CAMPUS THAT CARES

Good things find their way back.

FindIt is a lost & found noticeboard for college students and staff. A simple way to look out for your belongings, and each other.

Share a report

Choose Report Lost Item or Report Found Item. Add a useful description, category, location, date, and a contact method.

Report an item

Look for a match

Search the noticeboard and filter by category or status. Open an item's details and contact the reporter directly.

Browse items

Return it safely

Confirm ownership with a detail not in the listing. Meet in a public campus location, then mark the item as returned.

About this prototype

Demonstration reports are included. Reports are saved in a SQLite database on the server computer and are shared between browsers using that server. This local-only prototype has no accounts, ownership permissions, or college authentication. Anyone with access can update a report. External photos and fonts require internet access.

The backend is written in C. It validates reports and uses prepared SQL statements for registration, searching, category filters, status updates, and statistics. JavaScript connects the interface to the C server through an HTTP API. No WebAssembly is needed.
